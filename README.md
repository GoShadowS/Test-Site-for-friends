# 🚀 DemoVerse — сайт, где есть всё

Многостраничный сайт-песочница для проверки возможностей чистого **HTML + CSS + JavaScript** (без фреймворков и сборщиков). Сделан для публикации на **GitHub Pages**.

## 📄 Страницы (16)

| Страница | Что внутри |
|---|---|
| `index.html` | Хиро с частицами, печатающийся текст, тикер, виджеты, счётчики |
| `games.html` | 🐍 Змейка, 🔢 2048, ⭕ крестики-нолики (минимакс-ИИ), 🎯 угадай число, 🧠 память |
| `apps.html` | Калькулятор, задачи, заметки, секундомер/таймер, конвертеры, пароли, анализ текста, цвета |
| `quiz.html` | Квиз из 12 вопросов с пояснениями и рекордом |
| `gallery.html` | Галерея с фильтрами и лайтбоксом (картинки сгенерированы нейросетью) |
| `components.html` | UI-кит: кнопки, модалки, drawer, табы, аккордеон, карусель, тосты… |
| `forms.html` | Живая валидация, маска телефона, сила пароля, drag-n-drop файлов |
| `tables.html` | Таблица данных: сортировка, поиск, фильтры, пагинация, экспорт CSV |
| `media.html` | 🎹 пианино (Web Audio), 🥁 драм-машина, визуализатор звука, canvas-демо |
| `blog.html` + 3 статьи | Гайд по GitHub Pages, приёмы CSS, JS без фреймворков |
| `about.html`, `faq.html`, `contact.html` | О сайте, аккордеон FAQ, форма связи + карта |
| `404.html` | Кастомная страница ошибки с пасхалками |

## ✨ Фичи

- 🌗 Тёмная/светлая тема (сохраняется)
- 🏆 Система из 15 достижений (localStorage) + окно прогресса
- 🥚 Пасхалки: код Konami (матричный дождь), клики по логотипу, секреты 404
- 📴 PWA: `manifest.webmanifest` + Service Worker → работает офлайн
- 🔍 SEO: мета-теги, Open Graph, `sitemap.xml`, `robots.txt`
- 📱 Полностью адаптивный (бургер-меню, свайпы в играх)
- ⚡ 0 зависимостей, 0 сборки — просто статические файлы

## 🛠 Запуск локально

```bash
git clone https://github.com/GoShadowS/Test-Site-for-friends.git
cd Test-Site-for-friends
python3 -m http.server 8000
# откройте http://localhost:8000
```

Или просто откройте `index.html` двойным кликом — всё работает и с диска (кроме офлайн-кэша, ему нужен http/https).

## 🌐 Публикация на GitHub Pages

1. Запушьте файлы в ветку `main` репозитория.
2. **Settings → Pages → Source**: ветка `main`, папка `/ (root)` → **Save**.
3. Через ~минуту сайт доступен по адресу:
   `https://<username>.github.io/Test-Site-for-friends/`

Сайт использует только **относительные пути**, поэтому работает в подпапке GitHub Pages, локально и на любом другом хостинге.
