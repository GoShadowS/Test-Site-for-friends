Главная/О сайте

О проекте DemoVerse

Зачем этот сайт, как он устроен и из чего собран — коротко и честно.

🎯

Миссия

Показать максимум возможностей современного фронтенда на одном статическом сайте: от CSS-анимаций до Web Audio API — без единой внешней библиотеки.

📦

Формат

Чистые HTML, CSS и JS. Никаких npm, сборщиков и фреймворков. Скачал папку — открыл в браузере — всё работает. Идеально для GitHub Pages.

🎁

Пасхалки

На сайте спрятаны секреты: код Konami, достижение за клики по логотипу и матричный дождь. Найдите их все!

Таймлайн создания

Весь сайт — от идеи до деплоя — собран автоматизированным агентом за одну сессию.

Шаг 1

💡 Идея и план

Пользователь попросил «сайт со всем, что только возможно». Родился план: 16 страниц, десятки демо, единый дизайн и система достижений.

Шаг 2

🎨 Дизайн-система

CSS-переменные, тёмная и светлая темы, неоновые градиенты, стекло и плавные анимации — единый файл стилей на весь проект.

Шаг 3

🖼️ Генерация графики

Обложка и шесть картин для галереи сгенерированы нейросетью прямо во время сборки сайта.

Шаг 4

🎮 Игры и приложения

Змейка на canvas, 2048 с жестами, пианино на Web Audio, калькулятор, квиз, таблица с сортировкой и экспортом CSV.

Шаг 5

🚀 Публикация

PWA-манифест, Service Worker для офлайна, sitemap, robots.txt — и деплой на GitHub Pages из репозитория.
