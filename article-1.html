🐙 Как работает GitHub Pages

Что такое GitHub Pages

GitHub Pages — это бесплатный статический хостинг, встроенный в GitHub. Вы кладёте в репозиторий файлы index.html, CSS и JavaScript, а GitHub раздаёт их как сайт по адресу вида username.github.io/repo-name. Именно так работает тот сайт, который вы читаете.

«Статический» значит: сервер не исполняет ваш код, а просто отдаёт файлы. Никакого PHP, баз данных и бэкенда. Зато — бесплатно, быстро и с HTTPS из коробки.

Статические сайты пережили флеш, jQuery-эпоху и почти все модные фреймворки. Они просто работают.

Как включить за 3 шага

  1. Создайте репозиторий и загрузите в корень index.html (сайт без сборки) или собранные файлы.
  2. Откройте Settings → Pages.
  3. В разделе Source выберите ветку main и папку / (root), нажмите Save.

Через минуту-другую сайт появится по адресу, указанному в тех же настройках. Каждый push в выбранную ветку обновляет сайт автоматически.

# локально
git add .
git commit -m "обновление сайта"
git push origin main
# и всё — GitHub Pages сам пересоберёт и опубликует

Подводный камень: пути

Главная ошибка новичков — абсолютные ссылки вида /css/style.css. Для сайта в подпапке (username.github.io/repo/) они ломаются: браузер ищет файлы в корне домена.

Правило простое:

<!-- ❌ сломается на project-pages -->
<link rel="stylesheet" href="/css/style.css">

<!-- ✅ работает везде -->
<link rel="stylesheet" href="css/style.css">

Этот сайт целиком построен на относительных путях — поэтому он одинаково работает и в подпапке GitHub Pages, и локально с диска, и на любом другом хостинге.

Свой домен и HTTPS

В Settings → Pages можно указать кастомный домен: добавьте в DNS запись CNAME на username.github.io, а флажок «Enforce HTTPS» включит бесплатный сертификат. Перевыпускается он автоматически.

Ограничения

  • Рекомендуемый лимит — 1 ГБ репозитория и ~100 ГБ трафика в месяц;
  • мягкий лимит — 10 сборок в час (для сайтов с Jekyll);
  • никакого серверного кода — только статика и клиентский JS;
  • сайты публичных репозиториев бесплатны; приватные — только по платным тарифам.

Для блога, портфолио, документации или лендинга — более чем достаточно. Собственно, вы прямо сейчас сидите на таком сайте.
