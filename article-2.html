🎨 10 приёмов современного CSS

📅 2026⏱️ 6 мин чтенияCSS

Все приёмы ниже используются на этом самом сайте. Откройте DevTools и убедитесь — никакого Sass, никакого Tailwind, только CSS.

1. CSS-переменные — тема за 10 строк

Кастомные свойства делают тему переключаемой без перезагрузки: достаточно поменять атрибут на <html>.

:root { --bg: #0a0e1a; --text: #e9edf5; --accent: #7c3aed; }
[data-theme="light"] { --bg: #f3f5fb; --text: #1a2233; }
body { background: var(--bg); color: var(--text); }

2. clamp() — типографика без медиазапросов

Заголовки этого сайта масштабируются плавно между минимумом и максимумом:

h1 { font-size: clamp(2.1rem, 6vw, 4rem); }

3. Градиентный текст

.grad-text {
  background: linear-gradient(135deg, #7c3aed, #06b6d4);
  -webkit-background-clip: text;
  color: transparent;
}

4. backdrop-filter — стекло

Шапка этого сайта — полупрозрачное «стекло» с размытием фона:

.site-header {
  background: rgb(10 14 26 / .78);
  backdrop-filter: blur(14px);
}

5. aspect-ratio вместо костылей

.gal-item { aspect-ratio: 4 / 3; }

6. :has() — «родительский селектор»

Стилизуем родителя по содержимому — например, подсветим поле с ошибкой:

.field:has(.input.error) { border-radius: 12px; outline: 1px solid #ef4444; }

7. Auto-fit grid — «резиновые» карточки

.grid-auto { grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); }

Одна строка — и карточки сами перестраиваются под ширину экрана.

8. scroll-behavior и scrollbar-стили

html { scroll-behavior: smooth; }
::-webkit-scrollbar { width: 11px; }
::-webkit-scrollbar-thumb { background: linear-gradient(#7c3aed, #06b6d4); }

9. color-mix() — оттенки из переменных

.site-header { background: color-mix(in srgb, var(--bg) 78%, transparent); }

10. prefers-reduced-motion — уважение к пользователю

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .001s !important; }
}

Если пользователь попросил систему «меньше движения» — сайт обязан послушаться. Это и есть доступность.
