⚡ JavaScript без фреймворков: зачем и почему

📅 2026⏱️ 8 мин чтенияJavaScript

У этого сайта ~2000 строк JavaScript и ноль зависимостей. Пять игр, пианино, драм-машина, таблицы, квиз — всё это «ваниль». Ниже — API браузера, которые делают фреймворки необязательными, и честный рассказ о том, когда они всё-таки нужны.

Браузер уже умеет то, за чем раньше шли в npm

  • querySelector и querySelectorAll — выборка элементов в одну строку;
  • classList — управление классами без jQuery;
  • fetch — HTTP-запросы без axios;
  • шаблонные строки — интерполяция без шаблонизаторов;
  • делегирование событий — один listener на весь документ.
// делегирование: копирование кнопок по всему сайту
document.addEventListener("click", e => {
  const btn = e.target.closest("[data-copy]");
  if (btn) navigator.clipboard.writeText(btn.textContent);
});

IntersectionObserver вместо scroll-listener

Анимации «появления при прокрутке» на этом сайте работают через наблюдателя — без прослушивания scroll и лишних перерисовок:

const io = new IntersectionObserver(entries => {
  entries.forEach(en => {
    if (en.isIntersecting) {
      en.target.classList.add("visible");
      io.unobserve(en.target);
    }
  });
}, { threshold: 0.12 });

document.querySelectorAll(".reveal").forEach(el => io.observe(el));

Web Audio API — оркестр в консоли

Пианино и драм-машина на сайте «Медиа» синтезируют звук осцилляторами и шумовыми буферами. Ни одного mp3-файла:

const ac = new AudioContext();
const osc = ac.createOscillator();
osc.type = "triangle";
osc.frequency.value = 440; // нота A4
osc.connect(ac.destination);
osc.start();

localStorage — база данных без сервера

Тема, рекорды игр, достижения, задачи и заметки — всё хранится локально. Две строки вместо целого API:

localStorage.setItem("theme", "dark");
const theme = localStorage.getItem("theme") ?? "dark";

Canvas — движок игр в стандартной библиотеке

Змейка — это 120 строк: сетка 20×20, массив сегментов, setInterval и отрисовка прямоугольников. 2048 и вовсе обходится DOM-элементами.

Когда фреймворк всё-таки нужен

  1. Сложное состояние: десятки связанных сущностей и синхронизация — React/Vue сэкономят нервы;
  2. Командная разработка: conventions фреймворка важнее личных предпочтений;
  3. Роутинг и SSR: многостраничность с общими шаблонами и SEO — Next.js или Astro;
  4. Сроки: готовая экосистема компонентов ускоряет старт.
Правило большого пальца: если у вас контент-сайт, лендинг, игрушка или инструмент — сначала попробуйте ваниль. Скорее всего, хватит её.

Итог

Ванильный JS — это не аскеза, а осознанный выбор: меньше веса, нет сборки, код живёт вечно и работает в любом браузере. А если проект вырастет — фреймворк можно добавить позже, никуда он не денется.
