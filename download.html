Быстрый старт

Инструкция по установке за 4 шага

Переход со стандартного лаунчера займёт не более нескольких минут.

1

Скачайте и установите

Загрузите инсталлятор под вашу операционную систему с официального сайта и следуйте простым подсказкам мастера установки.

2

Добавьте аккаунт

В правом верхнем углу нажмите «Аккаунты» → «Добавить». Войдите через безопасное OAuth-окно Microsoft или создайте оффлайн-профиль.

3

Создайте инстанс

Нажмите «Добавить инстанс», выберите любую версию Minecraft и нужный загрузчик (Fabric, NeoForge или Forge) либо найдите готовый модпак.

4

Запустите и играйте

Добавьте желаемые моды через встроенный поиск прямо в лаунчере и нажмите «Запустить». Приятной игры с максимальным FPS!

Часто задаваемые вопросы (FAQ)

Всё, что вам нужно знать о безопасности, лицензиях и мультиплеере в Prism Launcher.

Да, абсолютно безопасно. Prism Launcher использует официальный протокол Microsoft OAuth 2.0. Вы вводите пароль исключительно на официальной странице авторизации Microsoft (login.live.com) в защищенном системном браузере. Лаунчер никогда не видит и не сохраняет ваш пароль, получая лишь временный зашифрованный токен сессии. Кроме того, код проекта на 100% открыт на GitHub и регулярно аудируется сообществом.
Для игры на официальных лицензионных серверах (например, Hypixel) и загрузки защищенных ресурсов вам потребуется официальная лицензия Minecraft Java Edition на вашей учетной записи Microsoft. Однако Prism Launcher также поддерживает оффлайн-аккаунты, что позволяет запускать игру без подключения к интернету или тестировать сборки локально.
Конечно! Prism Launcher запускает стандартный Minecraft. Вы можете подключаться к любым серверам (Hypixel, приватные SMP, модовые сервера), открывать мир для локальной сети (LAN) или использовать модификации вроде Essential и e4mc для прямой игры с друзьями без выделенного IP-адреса.
Очень просто. Откройте папку %appdata%/.minecraft/saves (на Windows), выберите папку нужного мира и скопируйте её. Затем в Prism Launcher нажмите правой кнопкой мыши по созданному инстансу → «Папка инстанса» → .minecraft → saves и вставьте мир туда. Ваши постройки и инвентарь сохранятся в первозданном виде.
В большинстве сборок Prism Launcher под Windows и macOS встроен инструмент автоматической загрузки подходящей Java Runtime. Если для старого модпака потребуется Java 8, а для свежей версии — Java 17/21, лаунчер сам подскажет это и предложит установить нужную среду исполнения в один клик.
