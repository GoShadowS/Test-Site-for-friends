DemoVerse — многостраничная «песочница», созданная для демонстрации возможностей чистого HTML, CSS и JavaScript: игр, инструментов, медиа, форм и графики. Он же — пример сайта для GitHub Pages, который можно форкать и переделывать под себя.
16: главная, «О сайте», игры, приложения, квиз, галерея, UI-кит, формы, таблицы, медиа, блог с тремя статьями, FAQ, контакты и страница 404. Плюс служебные файлы: манифест PWA, Service Worker, sitemap и robots.txt.

Правда. Service Worker кэширует страницы при первом визите, и после этого сайт открывается даже в офлайне (значок 📴 в некоторых браузерах). Работает только по HTTPS — например, на GitHub Pages.
Загрузите файлы в репозиторий, затем Settings → Pages → Source: ветка main, папка / (root), Save. Через минуту сайт будет доступен по адресу username.github.io/имя-репозитория. Подробности — в статье-гайде.
Все шесть изображений и обложка сгенерированы нейросетью прямо во время сборки сайта. Это честнее стоковых фото и красивее пустых заглушек — и не нарушает ничьи авторские права.
Любой современный: Chrome, Edge, Firefox, Safari (включая мобильные). Сайт не использует экспериментальных флагов — только стабильные API: Canvas, Web Audio, localStorage, IntersectionObserver, Service Worker.
